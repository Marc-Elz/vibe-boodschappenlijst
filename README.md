# Vibe Boodschappenlijst

A grocery list in a single HTML page, with products grouped into editable categories and a print option.

An AI-assisted ("vibe coded") practice project: the code was written by an AI from my prompts. My notes on what worked and what didn't in prompting are in [reflectie](reflectie) (Dutch). Archived small practice project.

## Tech stack

Plain HTML, CSS and JavaScript, no build step.

## Getting started

Open `boodschappen.html` in a browser.
